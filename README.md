# Tecatex Aerospace - Landing Page Oficial (Edición Espacial Animada)

Este repositorio contiene los archivos fuente del landing page estático interactivo para el proyecto aeroespacial **Tecatex Aerospace**.

## 📁 Estructura del Proyecto

```text
├── index.html   # Estructura principal con el logo emblemático (Luna + Botella)
├── styles.css   # Estilos CSS con animaciones orbitales y paleta monocromática oficial
├── script.js   # Código JavaScript para la animación interactiva del fondo espacial de estrellas
└── README.md    # Documentación e instrucciones
```

## 🚀 Guía de Despliegue en GitHub Pages

1. **Descomprimir:** Extrae el archivo ZIP.
2. **Subir a GitHub:** Carga `index.html`, `styles.css`, `script.js` y `README.md` en la raíz de tu repositorio.
3. **Activar Pages:** Ve a **Settings > Pages**, selecciona la rama `main` / `master` (root) y guarda los cambios.
